# 0.15.1 — An uppercase commit pin counts as pinned

`openaca-posture-mutable-install-reference` no longer flags a git reference
that pins a full commit SHA in uppercase.

## Highlights

- **An uppercase commit pin is immutable.** The mutable-reference check
  accepted only a lowercase 40-hex commit SHA. It now uses the MCP parser's
  commit pattern, which accepts either case. A pin such as
  `git+https://host/x/y.git@A1B2…` is no longer a posture finding. Pi git
  references use the same pattern.
- **One rule in one place.** The MCP parser, identity and the
  mutable-reference check share one uv option walker. Findings and posture
  share one `declared_by` reader. The graph normalizer and the legacy Claude
  MCP reader share one default-root test. Devin and OpenCode share one XDG
  reader. These changes do not change the BOM or scan output.

## Install

`uv tool install openaca==0.15.1` or `pip install openaca==0.15.1`.

## Compatibility

Pre-V0, no back-compat hedging. The BOM format does not change, and
`openaca:schema_version` stays `0.7`. A scan that flagged an uppercase commit
pin as `openaca-posture-mutable-install-reference` no longer flags it.
