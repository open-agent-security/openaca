# 0.13.2 — Internal cleanup

This release removes unused and duplicated internal code. Scans, BOMs, policy
evaluation and the CLI do not change.

## Highlights

- **Unused and duplicated helpers are removed.** The unused
  `tools.parsers.claude_plugin.parse_at_install_root` helper is gone. Endpoint
  scans call `walk_plugin_root` directly, as before. The BOM linter reuses the
  property map helper in `tools.bom`. The Skillspector observation source
  reuses the bom-ref helper of the skill posture rule.

## Install

`uv tool install openaca==0.13.2` or `pip install openaca==0.13.2`.

## Compatibility

Pre-V0 — no back-compatibility hedging.

- **`tools.parsers.claude_plugin.parse_at_install_root` is removed.** It was
  an internal helper with no caller. `openaca.core` does not change.
- **`openaca:schema_version` stays `0.6`.** The BOM document shape did not
  change.
- **The overlay record schema is unchanged.**
