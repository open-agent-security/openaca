# 0.15.2 — The BOM linter reads the kind registry

`openaca bom lint` now takes the allowed `openaca:composition_source` values
from the kind registry.

## Highlights

- **One set of composition sources.** The BOM linter kept its own copy of the
  allowed `openaca:composition_source` values. It now uses the set that the
  kind registry defines. The set is still `installed` and `declared`, so a BOM
  that passed the linter before still passes.

## Install

`uv tool install openaca==0.15.2` or `pip install openaca==0.15.2`.

## Compatibility

Pre-V0, no back-compat hedging. The BOM format does not change, and
`openaca:schema_version` stays `0.7`. The linter accepts and rejects the same
BOMs as in 0.15.1.
