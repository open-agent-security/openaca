# 0.9.1 — Devin is `devin`

Devin CLI and Devin Desktop's local agent are one program, reading one
configuration and writing one store, but 0.9.0 inventoried them as `devin-cli`,
named "Devin CLI". This release names the kind after the agent.

## Highlights

- **The Devin kind is `devin`, named Devin** (ADR-0075). `--kind devin` selects
  it, `bom endpoint` writes `devin.cdx.json`, the BOM's `openaca:agent_kind` is
  `devin` and its root is named "Devin". OpenAIDR 0.5.2 renames its session kind
  the same way, so a consumer joining the two keeps one name.

## Install

`uv tool install openaca==0.9.1` or `pip install openaca==0.9.1`.

## Compatibility

Pre-V0 — no back-compatibility hedging.

- **`devin-cli` is gone.** `--kind devin-cli` is refused as an unknown kind;
  there is no alias.
- **Devin BOMs change identity.** `openaca:agent_kind`, the root's name and
  label, and every Devin component's `bom-ref` prefix change with the kind, so
  a consumer that stored Devin components by `bom-ref` sees them as new.
- Claude Code, Cursor and Codex are unchanged.
