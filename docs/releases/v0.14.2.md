# 0.14.2 — Internal cleanup

This release removes a duplicated helper. Scans, BOMs, policy evaluation and
the CLI do not change.

## Highlights

- **The `pyproject.toml` parser reuses the shared PyPI name normalizer.** It
  called a private copy of the PEP 503 normalizer. It now calls
  `normalize_pypi_name` in `tools.mcp_launch_resolve`, which gives the same
  result.

## Install

`uv tool install openaca==0.14.2` or `pip install openaca==0.14.2`.

## Compatibility

Pre-V0 — no back-compatibility hedging.

- **Nothing changes for a consumer.** `openaca.core` does not change.
- **`openaca:schema_version` stays `0.7`.** The BOM document shape did not
  change.
- **The overlay record schema is unchanged.**
