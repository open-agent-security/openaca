# 0.10.0 — each agent's own sub-agents and skills

Every agent kind provides some sub-agents and skills itself: Claude Code's
`Explore` and `general-purpose`, Devin's `subagent_explore`, Codex's `.system`
skills. None was in a BOM, so a consumer joining an agent's activity to its BOM
couldn't tell a call to one from a call to something never installed. This
release lists them.

## Highlights

- **An installed agent's BOM root lists what the agent provides itself**
  (ADR-0076): `openaca:builtin_agents` and `openaca:builtin_skills` on
  `metadata.component`, each a JSON array of unique names.
  - Claude Code: 12 sub-agent types and 39 skills, read from Claude Code
    2.1.283's own definitions. It ships them inside the executable.
  - Devin: its four subagent profiles, read from Devin 3000.10.48.
  - Codex: its roles, and the skill names in its marker-bearing `skills/.system/`.
  - Cursor: the skill names in `skills-cursor/`.
- **Never components.** No posture rule, policy admission, vulnerability
  coverage, count or render sees them. ADR-0052's and ADR-0055's exclusions
  stand.
- **`bom lint`** refuses a built-in list that is not a JSON array of unique,
  non-empty strings.

## Install

`uv tool install openaca==0.10.0` or `pip install openaca==0.10.0`.

## Compatibility

Pre-V0 — no back-compatibility hedging.

- **Additive.** Installed agent BOMs gain the two optional root properties,
  absent where a kind lists none. Declared (repo) BOMs never carry them.
- Component lists, counts, posture and policy output are unchanged.
